# Fuentes: Fotografía

Portfolios, archivos fotográficos y colecciones de imágenes. Registrar autor,
procedencia y licencia cuando estén disponibles; una imagen visible o con URL
pública no es automáticamente reutilizable.

| Fuente | URL | Enfoque |
|---|---|---|
| 500px | https://500px.com/ | Comunidad y portfolios fotográficos. |
| Magnum Photos | https://www.magnumphotos.com/ | Ensayos y archivo de fotografía documental. |
| Unsplash | https://unsplash.com/ | Fotografía y API para aplicaciones bajo sus reglas específicas. |
| Pexels | https://www.pexels.com/ | Fotografías y videos; revisar licencia y términos por uso. |
| 1x | https://1x.com/ | Galería de fotografía curada. |
| National Geographic Photography | https://www.nationalgeographic.com/photography | Fotografía de naturaleza, viajes y reportaje. |
| LFI — Leica Fotografie International | https://lfi-online.de/ceee/en/gallery.html | Galería de fotografía Leica. |

## APIs relacionadas

- [Unsplash API](apis.md#apis-y-documentación-oficial): requiere aplicación
  registrada, atribución y hotlinking de imágenes según sus reglas.
- [Openverse](apis.md#apis-y-documentación-oficial): búsqueda de medios con
  licencias abiertas; conservar metadatos de licencia y atribución.
- [Wikimedia Commons](apis.md#apis-y-documentación-oficial): búsqueda y
  metadatos de imágenes libres con licencias diversas.
