# Fuentes: Videojuegos

Tiendas, archivos y proyectos interactivos. Una ficha gratuita o un juego
ejecutable en navegador no implica licencia para redistribuirlo.

| Fuente | URL | Enfoque |
|---|---|---|
| itch.io | https://itch.io/ | Juegos independientes, experimentales y proyectos de navegador. |
| Internet Archive — MS-DOS Games | https://archive.org/details/softwarelibrary_msdos_games | Archivo de juegos clásicos; acceso y derechos por ítem. |
| Game Jolt | https://gamejolt.com/ | Proyectos independientes y comunidad de juegos. |
| GOG.com | https://www.gog.com/ | Catálogo comercial de juegos clásicos y actuales. |
| MADE | https://www.themade.org/ | Museo de arte y entretenimiento digital. |
| Steam | https://store.steampowered.com/ | Catálogo comercial y fichas de juegos. |

## APIs relacionadas

- [IGDB](apis.md#apis-y-documentación-oficial): metadatos de juegos y compañías;
  uso no comercial gratuito según sus condiciones; requiere credenciales Twitch
  y OAuth.
- [Steam Web API](https://steamcommunity.com/dev): interfaz oficial de Steam;
  requiere clave para funciones que la necesitan. Revisar términos, alcance y
  límites antes de usar.
- [Internet Archive](apis.md#apis-y-documentación-oficial): búsqueda de registros
  de juegos archivados, con derechos y disponibilidad específicos por ítem.
