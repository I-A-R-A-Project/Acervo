# Fuentes: Música

Catálogos, actuaciones, partituras y plataformas de artistas. Guardar enlaces
y metadatos no equivale a permiso para descargar o redistribuir audio.

| Fuente | URL | Enfoque |
|---|---|---|
| Bandcamp | https://bandcamp.com/ | Música independiente y páginas de artistas/álbumes. |
| NPR Tiny Desk Concerts | https://www.npr.org/series/tiny-desk-concerts | Actuaciones y entrevistas musicales. |
| IMSLP / Petrucci Music Library | https://imslp.org/ | Partituras; confirmar derechos de cada edición y obra. |
| Classical Archives | https://www.classicalarchives.com/ | Catálogo y referencias de música clásica. |
| SoundCloud | https://soundcloud.com/ | Música y audio publicado por usuarios. |
| KEXP | https://www.youtube.com/@kexp | Sesiones y actuaciones del canal oficial. |

## APIs relacionadas

- [MusicBrainz](apis.md#apis-y-documentación-oficial): metadatos de artistas,
  grabaciones, lanzamientos y relaciones; no entrega audio.
- [Wikimedia Commons](apis.md#apis-y-documentación-oficial): archivos de audio
  disponibles bajo licencias variadas.
- [Bandcamp Developer](https://bandcamp.com/developer): documentación e
  información para desarrolladores de Bandcamp; confirmar disponibilidad,
  aprobación y condiciones de acceso vigentes.
- [SoundCloud API](https://developers.soundcloud.com/docs/api/guide): guía de la
  API de SoundCloud; revisar registro de aplicación, permisos y límites actuales.
- [Spotify Web API](https://beta.developer.spotify.com/documentation/web-api/):
  documentación de la Web API; revisar requisitos de aplicación, OAuth y
  políticas vigentes antes de integrarla.
