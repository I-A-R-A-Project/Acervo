# Fuentes y APIs de las Salas de Arte

Este directorio reúne fuentes web para las nueve salas de arte y documentación
oficial de APIs que podrían servir para descubrir metadatos o contenido. Cómics,
manga y fanfiction pertenecen a **Literatura**; no hay una sala separada de
Cómics.

## APIs

Consulta el [índice de documentación oficial de APIs](apis.md) para enlaces,
acceso gratuito, autenticación, límites y consideraciones de uso. Son opciones
para evaluar, no adaptadores implementados ni garantía de acceso permanente.

Una API pública o gratuita no concede derechos sobre las obras que describe.
Antes de integrar una fuente, revisar sus términos, licencias por ítem, límites
de uso y, cuando corresponda, `robots.txt`. Priorizar guardar la URL y
atribución; no descargar ni redistribuir contenido protegido sin autorización.
